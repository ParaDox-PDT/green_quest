# Green Quest

Green Quest is a nature-inspired, cheerful, and children-friendly 2D Roll-and-Move "Race Board Game" built using Flutter.

## Features

- **Splash Screen**: Beautiful, smooth fade-in nature logo animation.
- **Localization**: Supports English, Russian, and Uzbek languages dynamically.
- **Design System**: Warm, vibrant nature-inspired pastel color palette with playful custom rounded typography.
- **State Management**: Robust state architecture driven by Riverpod.

## Setup & Running

1. **Get Dependencies**:
   ```bash
   flutter pub get
   ```
2. **Generate Localization Files**:
   ```bash
   flutter gen-l10n
   ```
3. **Run the Project**:
   ```bash
   flutter run
   ```
